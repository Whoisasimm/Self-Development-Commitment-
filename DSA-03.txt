range(k)
If k = 3, range(k) means range(3), which produces 0, 1, 2.
range() produces index values when used with a list.
numbers[i] uses i as an index to access a value from the list.

Example:
numbers = [2, 1, 5, 1, 3, 2]
k = 3

range(k) gives:
0, 1, 2

numbers[0] = 2
numbers[1] = 1
numbers[2] = 5

for i in range(k):
    window_sum += numbers[i]

This calculates the first k elements.

DSA

SLIDING WINDOW

Sliding Window is used when we work with a continuous part of an array or string.

For a fixed window, k tells us the number of elements inside the window.

Example:
numbers = [2, 1, 5, 1, 3, 2]
k = 3

Windows:
[2, 1, 5] = 8
[1, 5, 1] = 7
[5, 1, 3] = 9
[1, 3, 2] = 6

Maximum sum = 9
Maximum window = [5, 1, 3]

Instead of calculating every window from zero, we reuse the previous sum.

First window:
2 + 1 + 5 = 8

When the window moves right:
2 leaves the window
1 enters the window

New sum:
8 - 2 + 1 = 7

The core formula is:

new_sum = old_sum - outgoing_value + incoming_value

In code:
window_sum = window_sum - numbers[i - k] + numbers[i]

numbers[i - k] is the value leaving the window.
numbers[i] is the value entering the window.

Fixed Sliding Window Complexity:
Time = O(n)
Extra Space = O(1)

Basic structure:
First calculate the sum of the first k elements.
Store it as the current best.
Move the window one position at a time.
Remove the outgoing value.
Add the incoming value.
Compare the new sum with the best sum.

TWO POINTERS VS SLIDING WINDOW

Two Pointers:
Usually uses two positions such as left and right.
The pointers can move independently according to the problem.

Sliding Window:
Maintains a continuous range of elements.
For a fixed window, the window size stays equal to k.
When it moves right, one value leaves and one value enters.

SQL

AGGREGATE FUNCTIONS

COUNT(*) counts rows.
SUM(column) calculates the total.
AVG(column) calculates the average.
MIN(column) finds the minimum.
MAX(column) finds the maximum.

GROUP BY

GROUP BY combines rows having the same value into groups.
Aggregate functions can then calculate a result for each group.

Example:
SELECT Department, AVG(Salary)
FROM Employees
GROUP BY Department;

HAVING

HAVING filters groups after GROUP BY.
WHERE filters individual rows before grouping.

Logical idea:
WHERE
GROUP BY
HAVING

NULL

NULL represents missing or unknown data.
NULL is not the same as 0.
NULL is not the same as an empty string.

Correct:
WHERE column IS NULL

Correct:
WHERE column IS NOT NULL

Incorrect:
WHERE column = NULL

COALESCE

COALESCE returns the first non-NULL value.

Example:
COALESCE(Salary, 0)

If Salary has a value, that value is returned.
If Salary is NULL, 0 is returned.

JOIN

JOIN combines related data from multiple tables.

Example tables:

EMPLOYEES
Employee_ID
Name
Department_ID

DEPARTMENTS
Department_ID
Department

Basic INNER JOIN:

SELECT Employees.Name, Departments.Department
FROM Employees
INNER JOIN Departments
ON Employees.Department_ID = Departments.Department_ID;

INNER JOIN returns rows where the matching condition is satisfied.

ON specifies how the tables are related.

Example:
Employee Ali has Department_ID 1.
Department 1 is AI.
The join produces Ali and AI.

If a department has no matching employee or an employee has no matching department, an INNER JOIN does not return that unmatched row.
